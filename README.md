# .github

Organisation-wide files for [Webos-Flutter-Legacy-TV](https://github.com/Webos-Flutter-Legacy-TV):

- `profile/README.md`: the organisation's profile page
- `ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE.md`: default issue forms and pull request template for every repository that doesn't have its own
- `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, `SUPPORT.md`: shared community files
